# Git Repository Auto-Update Rule

Every time modifications, bug fixes, UI enhancements, or new features are added to this codebase:
1. Confirm the project builds cleanly without errors (`npm run build`).
2. Proactively stage and commit changes with a descriptive semantic commit message.
3. Push to `origin main` (`https://github.com/salmanashrafsolutions/logistics-tracking`) so that Vercel auto-deploys the latest production build immediately.
